
Front-end: Sistema de Gestão de Manutenção Industrial 🛠️

Este repositório contém a interface do usuário para o sistema de gestão de ativos e ordens de serviço. O projeto visa digitalizar processos de RCM (Manutenção Centrada na Confiabilidade), permitindo o controle de criticidade e histórico de equipamentos.

    Status do Projeto: 🚧 Em desenvolvimento ativo.
    O foco atual está na implementação das regras de negócio e integração com a API em Java/Spring Boot.

🚀 Tecnologias Utilizadas

    Framework: Angular

    Linguagem: TypeScript.


🛠️ Desafios Atuais e Débitos Técnicos

Como o projeto está em fase de construção, decidi documentar abertamente os pontos que estão sob melhoria:

    UI/UX: O layout ainda está em estágio de prototipagem funcional. A prioridade atual é a funcionalidade das rotas e o fluxo de dados, com refinamento visual planejado para as próximas sprints.

    CI/CD (GitHub Actions): Atualmente, os workflows de automação estão em fase de ajuste para lidar com as especificidades do ambiente de deploy.
